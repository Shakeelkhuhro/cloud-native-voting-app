# Cloud Native Voting Application

A production-style cloud native voting application deployed using Kubernetes and Helm.

## Architecture

The application consists of:

- Vote Service (Python Flask)
- Result Service (Node.js)
- Worker Service (.NET)
- Redis Queue
- PostgreSQL Database

## Kubernetes

Deployment features:

- Kubernetes Deployments
- Services
- ConfigMaps
- Secrets
- StatefulSets
- Persistent Volumes
- Helm Parent Chart
- Helm Subcharts
- Bitnami Dependencies

## DevOps Stack

- Docker
- Kubernetes
- Helm
- Kind
- GitHub Actions
- Prometheus
- Grafana
- ArgoCD
